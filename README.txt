שעות ושכר — גרסה 22 (PWA)

איך מתקינים באנדרואיד:
1. יש להעלות/לפתוח את התיקייה דרך שרת HTTPS.
2. לפתוח את index.html דרך Chrome.
3. בתפריט Chrome לבחור "התקנת אפליקציה" / "הוסף למסך הבית".
4. לאחר ההתקנה האפליקציה נפתחת כחלון עצמאי ועובדת גם ללא אינטרנט לאחר הטעינה הראשונה.

חשוב:
- הנתונים נשמרים מקומית במכשיר בדפדפן.
- מפתחות הנתונים הקיימים נשמרו ולא שונו.
- זו אפליקציית PWA. APK אמיתי דורש עטיפה/בנייה עם Android SDK.


גרסה 23:
